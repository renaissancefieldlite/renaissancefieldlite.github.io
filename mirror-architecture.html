Program 01 / Mirror Architecture

AI state that can be measured, remembered, and recovered.

Mirror Architecture is Renaissance Field Lite's AI-agnostic state, memory, evidence, and control system. It keeps track of what state an AI is in, what evidence supports that state, what changed, what remains uncertain, and what gate should come next.

What it does

One system holds the thread from observation to next action.

Most AI interfaces preserve a conversation. Mirror Architecture preserves the operating state around the conversation: evidence, controls, corrections, uncertainty, unfinished work, and the next acceptance gate.

Observe Measure the state path

Compare target behavior with matched controls, then inspect the internal or external measurements that produced the result.

Remember Keep evidence with the state

Store state changes, source paths, receipts, corrections, uncertainty, and unfinished obligations instead of saving only the final answer.

Govern Advance through measured gates

Plans, mutations, and claims move forward only when the declared evidence and acceptance conditions are satisfied.

Recover Resume without rebuilding the context

Compaction records, handoffs, task notes, and SQ67 receipts restore the causal thread after interruption or model change.

Implemented state stack

The architecture now exists as software, not only as a research diagram.

Durable state

SQLite + atomic snapshots

Conversation state, events, memories, compactions, handoffs, and task notes are stored locally and mirrored into recoverable JSON snapshots.

Evidence memory

Semantic recall with source boundaries

Local retrieval combines messages, pinned memory, metadata, and semantic ranking while keeping source identity and evidence role visible.

Runtime governance

Plans that cannot finish on assertion

The planner preserves completed evidence, audits source freshness, requires mutation contracts, and blocks completion until acceptance gates pass.

Measured control

Bounded state and gradient layers

Current runtime tools measure aggregate state geometry and derive bounded conversation controls without persisting raw hidden states or biometric streams.

Evidence layer

The original measured state path still sets the standard.

The state system does not replace the research stack. It uses that stack to decide what earns support. A result must remain distinguishable from neutral, shuffled, semantic-counter, random, null, or domain-specific baseline controls.

Behavior to internals V7 / V8

Target and control behavior moved into rerun checks, hidden-state traces, layer localization, and context-to-readout analysis.

Internals to payload Bridge rows and feature vectors

Measured fields became bounded numerical objects that could be compared, transported, and tested outside the original model surface.

Payload to carriers Circuits, data, and devices

Quantum, materials, biological, and runtime adapters test whether structure survives a new carrier without erasing its controls.

Result to system Receipts, routing, and next gates

Supported results can update evidence memory and routing. Open or failed results remain visible instead of being promoted into system truth.
